☁️ Шинэ Firebase Project Холбох

Холбогдоогүй
Шинэ Firebase Project-оо хэрхэн холбох вэ?

1. Firebase Console дээр шинэ Project үүсгээд Firestore Database болон Authentication (Anonymous / Email / Google)-ийг идэвхжүүлнэ.

2. Project Settings → Web App хэсгээс firebaseConfig объектын JSON кодыг доорх нүдэнд хуулж «Хадгалах & Холбох» товчийг дарна уу.

3. Эсвэл HTML код доторх DEFAULT_FB_CONFIG хэсэгт шууд бичиж хадгалж болно.
